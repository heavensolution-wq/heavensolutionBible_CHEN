성경 · 요계 암송 — 설치형 웹앱(PWA)
(개역한글 성경 읽기·통독 + 요한계시록 암기 + 천제고 모의고사, 中文 · English 함께 보기)

────────────────────────────
1. 수정본 올리기 — 쓰던 주소 그대로
────────────────────────────
이 폴더의 파일 전체를 지금 쓰고 있는 주소(같은 프로젝트)에 덮어 올리세요.
  · Netlify: 그 프로젝트 → Deploys 탭 맨 아래 업로드 영역에 폴더를 끌어다 놓기
  · GitHub + Cloudflare Pages: 저장소의 파일을 이 폴더 내용으로 바꿔 커밋(푸시)
    → Cloudflare Pages가 자동으로 다시 배포
새 파일 web.json(영어 성경)이 꼭 함께 올라가야 합니다. 예전 kjv.json은 지워도 됩니다.

────────────────────────────
2. 가름끈·메모·하이라이트·시험 기록은 그대로인가요?
────────────────────────────
네. 같은 주소에 덮어 올리면 기기에 저장된 자료(가름끈·시험지·오답노트·통독 진도·
암기 플랜·모의고사 기록과 오답노트·깨달음 메모·하이라이트)는 그대로 남습니다.
자료는 '앱 주소'마다 따로 저장되므로, 주소가 바뀔 때(예: Netlify → Cloudflare Pages)만
옮기는 작업이 필요합니다:
  ① 옛 주소의 앱 → 자료 탭 → 백업 내보내기 (파일 1개)
  ② 새 주소의 앱 → 자료 탭 → 백업 가져오기
기기마다(폰·맥북) 한 번씩 하면 됩니다.

────────────────────────────
3. 설치
────────────────────────────
아이폰: Safari로 주소 열기 → 공유(□↑) → 홈 화면에 추가
맥: Chrome으로 주소 열기 → 주소창 오른쪽 설치 아이콘(⊕)
